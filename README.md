# TALK for Homebrew

A Homebrew tap for **TALK** — a menu-bar hold-to-talk dictation app for macOS. Hold a key, speak, and the transcript is typed at your cursor: Gemini cloud models for accuracy, with an on-device Whisper Turbo that rescues the round when the cloud is unreachable.

## Install

```sh
brew tap SaranH8/talk
brew trust SaranH8/talk
brew install --cask talk
```

## Update

```sh
brew upgrade --cask talk
```

Or click the "Update available" line in TALK's menu when it appears — the app updates itself and relaunches.

More about TALK: https://cathunters.com/hub
